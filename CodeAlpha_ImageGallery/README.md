## 🌟 Key Features

- **📱 Fully Responsive Design**: Built using modern CSS3 Grid (`repeat(auto-fill, minmax(290px, 1fr))`) and Flexbox that flawlessly adapts to mobile phones, tablets, and ultra-wide desktop monitors.
- **🔍 Real-Time Search Filtering**: Instant fuzzy search across titles, descriptions, categories, and tags.
- **🏷️ Category Filtering**: Filter cards smoothly by Nature, Architecture, Technology, Travel, and Wildlife categories.
- **🖼️ Interactive Lightbox Modal**:
  - Full-screen high-resolution image preview with loading spinner.
  - Previous (`<`) & Next (`>`) navigation with infinite circular cycling.
  - Thumbnail strip for quick direct jumping.
  - Fullscreen toggle & download button.
- **⌨️ Keyboard Navigation**:
  - `ArrowLeft` / `ArrowRight`: Navigate through images.
  - `Escape`: Close lightbox.
  - `F`: Toggle full-screen mode.
- **👆 Mobile Touch Swipe Gestures**: Smooth swipe-left and swipe-right gesture detection for mobile devices.
- **✨ Micro-Interactions & Hover Effects**: Glassmorphism backdrop blur, card hover lift, image scale zoom, and glowing accents.

---

## 🛠️ Built With

- **HTML5**: Semantic tags (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`).
- **CSS3**: Custom CSS Variables, Glassmorphism, CSS Grid, Flexbox, Keyframe Animations.
- **Vanilla JavaScript (ES6+)**: Clean, modular event-driven code without third-party frameworks.
- **Google Fonts & FontAwesome**: Plus Jakarta Sans typography and modern icons.

## 🚀 How to Run Locally

1. Clone or download this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/CodeAlpha_ImageGallery.git
   ```
2. Navigate to the project directory:
   ```bash
   cd CodeAlpha_ImageGallery
   ```
3. Open `index.html` directly in your browser:
   - Double click `index.html` in your file explorer, OR
   - Run via PowerShell:
     ```powershell
     Start-Process index.html
     ```
   - Or use VS Code Live Server extension.
